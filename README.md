# RestoreEncore
Восстановление имён и расширений потерянных файлов. Распознаёт музыку через Shazam, читает ID3/EXIF. Ищет дубликаты MP3.
# 🎵 RestoreEncore

**Возвращает имена и расширения файлам, которые их потеряли.**

Компактная GUI-утилита на PyQt6 для восстановления имён файлов после сбоя файловой системы, неудачного восстановления из корзины или случайного «скрытия» папок. Определяет тип по сигнатуре, читает метаданные (ID3, EXIF, core.xml), распознаёт аудио через Shazam. Отдельным режимом — поиск и удаление дубликатов MP3.

## 📖 О проекте

Бывает, что после сбоя файловой системы, неудачного восстановления из корзины или случайного «скрытия» папки файлы теряют **имена и расширения**. Данные при этом целы: музыка играется, картинки открываются, документы читаются. Пропадает только «обёртка».

**RestoreEncore** решает эту проблему:

- Определяет тип файла по **сигнатуре** (первые байты), а не по расширению.
- Восстанавливает имя из **метаданных**, если они сохранились.
- Если метаданных нет — **зовёт Shazam**, чтобы узнать трек по звуку.
- В крайнем случае даёт понятное имя по номеру: `mp3_00001.mp3`.

Отдельная вкладка ищет **дубликаты MP3** по MD5 и ID3-тегу — без `ffmpeg`, `fpcalc` и прочих тяжёлых зависимостей.

> ⚠️ **Важно:** RestoreEncore **не восстанавливает удалённые файлы**. Она работает с файлами, которые физически есть на диске, но потеряли имя и расширение. Для восстановления удалённых нужен другой класс софта: R-Studio, Recuva, PhotoRec.

## ✨ Возможности

### Вкладка «Восстановление»

| Формат | Откуда берётся имя |
|---|---|
| **MP3** | ID3 (`TPE1` / `TIT2` / `TRCK`) |
| **FLAC / OGG** | Vorbis-комментарии |
| **JPG** | EXIF `DateTimeOriginal` → `IMG_2023-05-12_18-34-56.jpg` |
| **DOCX / XLSX / PPTX** | `docProps/core.xml` (title, creator) |
| **PNG, GIF, BMP, WEBP, PDF, ZIP, RAR, 7Z, MP4, AVI, MKV, MOV, WAV** | Возврат расширения, имя по номеру |

**Распознавание аудио без тегов** — через Shazam. Пробуется несколько смещений в файле:
60с (припев) → 30с → 90с → 15с → 0с (по умолчанию)

text

Это повышает шанс узнать трек, если стандартный сэмпл из середины попадает на проигрыш.

**Опции:**
- ✅ Копировать (оригиналы не трогаются, восстановленные идут в `restored/`).
- ✅ Удалять оригиналы после успешного восстановления (с подтверждением).
- ✅ Снять атрибуты `скрытый / системный / только чтение` перед обработкой.
- ✅ Отключить Shazam — если нет интернета или не нужно.

### Вкладка «Дубликаты MP3»

- Сканирует папки и отдельные файлы.
- Группирует по **MD5 всего файла** (точные копии) и по **ID3-тегу** `artist|title|album` (один трек в разных битрейтах).
- Оставляет один файл из группы: с самым высоким битрейтом → с большей длительностью → с большим размером.
- Три действия: **показать** / **переместить в `duplicates/`** / **удалить безвозвратно**.
- В списке результатов: `★` — оставить, `×` — дубликат (красным).

### Интерфейс

- Компактное окно **400×860**.
- **Drag & drop** папок и файлов.
- **Тёмная и светлая тема** в стиле Windows 11.
- Прогресс в реальном времени: `исходное_имя → новое_имя`.
- Зелёным — восстановленные из метаданных, серым — по номеру.
- Список поддерживает **Del** для удаления из очереди.
- Иконка: синяя нота — генерируется программно, встроена в `.exe`.

### Устойчивость

- Файлы с непечатаемыми символами в имени (`\x00`) — типичный результат повреждения ФС — **не валят всю обработку**. Они пропускаются, счётчик «битых» показывается в итогах.
- Все операции обёрнуты в `try/except` — падение на одном файле не останавливает остальные.

🔧 Как это работает
1. Определение типа по сигнатуре
Файл читается побайтово, первые 16 байт сравниваются с таблицей сигнатур:

python
SIGNATURES = [
    ("jpg",  0, b"\xFF\xD8\xFF"),
    ("png",  0, b"\x89PNG\r\n\x1a\n"),
    ("pdf",  0, b"%PDF"),
    ("zip",  0, b"PK\x03\x04"),
    ("flac", 0, b"fLaC"),
    # ...
]
Если расширение потеряно — это единственный надёжный способ определить формат.

2. Извлечение имени
MP3 → mutagen.id3.ID3 → теги TPE1, TIT2, TRCK.

JPG → PIL.Image → EXIF DateTimeOriginal.

DOCX / XLSX / PPTX → открывается как ZIP, читается docProps/core.xml.

3. Shazam fallback
Если тегов нет, файл отправляется в Shazam через shazamio.recognize(path, offset=N). Пробуются разные offset, первый успешный результат — побеждает.

4. Дубликаты MP3
MD5 всего файла → точные байт-в-байт копии.

ID3 artist|title|album в нижнем регистре → один трек в разных битрейтах.

Правило выбора «хранителя» группы: битрейт → длительность → размер.

❓ FAQ
Q: Программа не восстанавливает удалённые файлы?

Нет, и не должна. Она работает с файлами, которые физически есть на диске, но потеряли имя и расширение. Для восстановления удалённых нужен R-Studio, Recuva, PhotoRec.

Q: Shazam не работает — No module named 'shazamio'

Три причины:

Не установлен: pip install shazamio shazamio-core.

Установлен в другой Python (user-site vs системный). Проверь: python -c "import sys; print(sys.executable)" — путь должен совпадать с тем, куда ставил pip.

Запускается .exe, собранный без --collect-all shazamio. Пересобери через build.bat.

Q: Shazam распознаёт не тот трек

Это ограничение Shazam: у него спектральные отпечатки, и инди-треки иногда совпадают с популярными по структуре. Попробуй отключить Shazam для таких файлов и переименовать вручную.

Q: WinError 123: Синтаксическая ошибка в имени файла

В имени файла есть непечатаемый символ (обычно \x00) — следствие повреждения ФС. Утилита такие файлы пропускает и считает в счётчике «битых». Их можно попробовать переименовать вручную с префиксом \\?\.

Q: Файлы уже назывались нормально, зачем переименовывать?

Не переименовывай. Оставь галочку «Копировать» и просто выбери один файл — он скопируется в restored/ с тем же именем.

Q: Работает на macOS / Linux?

В теории да — PyQt6 и mutagen кроссплатформенные. Но attrib и explorer — Windows-only. На других ОС надо отключить галочку «Снять атрибуты» и заменить открытие папки в проводнике на open / xdg-open.
